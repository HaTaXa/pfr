# pfr
Web-презентация ПО - Проект база данных «Учет заявок ФГИС "ФРИ"» для МИЦ ОВИВ ПФР по мониторингу, контролю и статистики заявок ФГИС «ФРИ» в АСТП

Проект «Учет заявок ФГИС "ФРИ"» - это база данных мониторинга статуса и состояния заявок, созданных в ФГИС «ФРИ»* - единой базе данных для граждан, признанных в установленном порядке инвалидами, и для органов власти, которые оказывают услуги или меры социальной поддержки инвалидам.

*ФГИС «ФРИ» - ФЕДЕРАЛЬНАЯ ГОСУДАРСТВЕННАЯ ИНФОРМАЦИОННАЯ СИСТЕМА «Федеральный реестр инвалидов».
